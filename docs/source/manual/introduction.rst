Introduction
------------

Yosuf is a Yosys-based open-source synthesis engine for eFPGA architectures hosted by ReFACT.

- Include yosys-plugin to enable in-house synthesis recipe and dedicated optimization 
- Include primitive libraries to support ReFACT eFPGA architectures

Yosuf aims to provide simplfied RTL synthesis interface for

- eFPGA architecture exploration tools 
- eFPGA end-user design tools
