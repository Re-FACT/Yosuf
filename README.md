# Yosuf

[![Test](https://github.com/Re-FACT/Yosuf/actions/workflows/test.yml/badge.svg)](https://github.com/Re-FACT/Yosuf/actions/workflows/test.yml)
[![Code Format](https://github.com/Re-FACT/Yosuf/actions/workflows/format.yaml/badge.svg)](https://github.com/Re-FACT/Yosuf/actions/workflows/format.yaml)

Version: see [`VERSION.md`](VERSION.md)

Yosuf is a Yosys-based Open-source Universal Frontend for FPGA architectures hosted by ReFACT

- [SOFA series](https://github.com/lnis-uofu/SOFA.git): SOFA-HD, QLSOFA-HD, SOFA-CHD, SOFA-PLUS-HD

## Getting Started

Yosuf supports a wide range of operating systems:

- Linux (Ubuntu, CentOS etc.)
- Windows (Msys2)
- MacOS

To build from source code, run the following command

```
git clone https://github.com/Re-FACT/Yosuf.git
cd Yosuf
make all
make quick_test
```
